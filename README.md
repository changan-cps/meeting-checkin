# Meeting Check-in

แอปเช็คอินเข้าร่วมประชุมด้วย QR Code ไม่ต้อง login

- **ตารางการประชุม** — ผู้จัดสร้างการประชุมไว้ล่วงหน้า กด "เปิด QR" เพื่อฉายบนจอ
- **QR เปลี่ยนทุก 15 วินาที** — ส่งลิงก์หรือถ่ายรูป QR ไปเช็คอินนอกห้องไม่ได้ (QR ใช้ได้ไม่เกิน 30 วินาที) และ **สแกน 1 ครั้ง เช็คอินได้ 1 คน**
- **เปิด–ปิดสแกนตามเวลา** — เช่น สแกนได้ 13:00–15:30 ของวันที่กำหนดเท่านั้น เช็คอินหลัง 14:00 นับเป็น **สาย**
- **ค้นหาชื่อ** — ผู้เข้าร่วมพิมพ์ชื่อบางส่วน ระบบแสดงรายชื่อที่ตรงกันให้แตะเลือก ถ้าไม่มีชื่อ กด "เพิ่มชื่อใหม่" ระบบเพิ่มเข้ารายชื่อของส่วนงานอัตโนมัติ
- **ประวัติแต่ละรอบ** — ตารางการประชุมแสดงจำนวนผู้เข้า/ผู้ต้องเข้า/สาย ของทุกรอบ กด "ดูรายชื่อ" เพื่อดูเช็คลิสต์และดาวน์โหลด CSV

ไฟล์:
- `index.html` — ตัวแอป (วางบน GitHub Pages)
- `Code.gs` — ส่วนเก็บข้อมูลและตรวจ QR บน Google Sheet

ระบบสร้างชีตใน Google Sheet ให้อัตโนมัติ

| ชีต | เก็บอะไร |
|---|---|
| Meetings | ตารางการประชุม (วันที่, เปิดสแกน, สายหลัง, ปิดสแกน, ส่วนงาน) |
| Departments | ส่วนงาน |
| Members | ฐานข้อมูลผู้ต้องเข้าประชุม แยกตามส่วนงาน |
| Checkins | บันทึกการเช็คอินทุกรอบ |

## ขั้นที่ 1 — ตั้งค่า Google Sheet (ทำครั้งเดียว ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `Meeting Check-in`
2. เมนู **Extensions > Apps Script** ลบโค้ดเดิม วางเนื้อหาทั้งหมดจาก `Code.gs`
3. **เปลี่ยน `ADMIN_PIN`** บรรทัดบนสุดเป็นรหัสของคุณ (ใช้เข้า ตารางการประชุม และ จัดการรายชื่อ) แก้ `DEFAULT_DEPARTMENTS` เป็นส่วนงานของโรงงานได้ กด Save
4. **Deploy > New deployment** เลือก **Web app** — Execute as: **Me**, Who has access: **Anyone** — กด Deploy อนุญาตสิทธิ์
5. คัดลอก **Web app URL** (ลงท้าย `/exec`)

> แก้ `Code.gs` ภายหลัง ต้อง Deploy > Manage deployments > Edit > Version: New version ทุกครั้ง

## ขั้นที่ 2 — ใส่ URL ในแอป

ใน `index.html` ด้านบน วาง URL ที่ `API_URL` (แก้บน GitHub ได้: เปิดไฟล์ > ไอคอนดินสอ > Commit changes)

```js
API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

เวลาเปิด/สาย/ปิด ตั้งต้นของฟอร์มอยู่ที่ `DEFAULT_OPEN`, `DEFAULT_LATE`, `DEFAULT_CLOSE`

## ขั้นที่ 3 — ใส่ฐานข้อมูลผู้ต้องเข้าประชุม

เปิดแอป > **จัดการรายชื่อ** > ใส่ PIN > เลือกส่วนงาน > วางรายชื่อหนึ่งชื่อต่อบรรทัด (คัดลอกคอลัมน์ชื่อจาก Excel มาวางได้) หรือแก้ในชีต `Members` โดยตรง
ชื่อที่ผู้เข้าร่วมเพิ่มเองจะขึ้นป้าย "เพิ่มตอนเช็คอิน" — กด ยืนยัน หรือ ลบ

## วิธีใช้

1. เปิดแอป ใส่ PIN > **สร้างการประชุม** (ชื่อ, วันที่, เปิดสแกน 13:00, สายหลัง 14:00, ปิดสแกน 15:30, ส่วนงานที่ต้องเข้า)
2. วันประชุม เปิดแอปบนเครื่องที่ต่อจอ กด **เปิด QR** > **ฉาย QR เต็มจอ**
   (หรือ "คัดลอกลิงก์" ไปเปิดบนเครื่องฉาย ลิงก์นี้เปิดหน้าผู้จัดได้โดยไม่ต้องใส่ PIN — อย่าส่งให้ผู้เข้าร่วม)
3. ผู้เข้าร่วมสแกน > พิมพ์ชื่อบางส่วน > แตะชื่อ > กดเช็คอิน
4. หน้าผู้จัดแสดงเช็คลิสต์ตามส่วนงานแบบสด: มาแล้ว / สาย / ยังไม่มา
5. ดูย้อนหลังได้ที่ **ตารางการประชุม > ประวัติการประชุม > ดูรายชื่อ** และกด **ดาวน์โหลด Excel (CSV)**

## ข้อควรรู้

- QR ต้องสแกนจากจอในห้องเท่านั้น ลิงก์จากการสแกนใช้ได้ครั้งเดียว ถ้าจะเช็คอินให้อีกคนต้องสแกนใหม่
- หลังสแกน ต้องกดเช็คอินภายใน 10 นาที (`TICKET_MINUTES`)
- เวลาเช็คอินและการตัดสินว่าสาย ใช้เวลาของเซิร์ฟเวอร์ Google (เวลาไทย) ไม่ใช่เวลาบนมือถือ
- ไม่มีการ login ผู้เข้าร่วมจึงเลือกชื่อใดก็ได้ แต่ต้องอยู่หน้าจอในห้องตอนสแกน
- ถ้ายังไม่ใส่ `API_URL` แอปทำงานในโหมดทดลอง (PIN ทดลอง 1234) เก็บข้อมูลเฉพาะเครื่องเดียว ใช้ดูหน้าตาได้
